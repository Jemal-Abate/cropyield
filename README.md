# Crop Yield Prediction Using Satellite Data and Machine Learning
This repository contains the source code, notebooks, datasets (where permitted), and trained models accompanying the following publication:
  Abate, J., Aman, A., & Adem, D. (2025). Integration of satellite data for predicting crop yields in Eastern Ethiopia using machine learning. Scientific Reports, 15, 33809. https://doi.org/10.1038/s41598-025-00810-z
